oraja-constellator v1.0.17
================================


このツールについて
------------------
oraja-constellatorは、難易度表内に譜面を、
傾向・密度・プレイ状況などの条件でまとめ、
目的に合ったカスタムフォルダーを構成するツールです。

例
・未プレイの譜面だけを表示
・HARD未達の譜面だけを表示
・最終プレイから30日以上経過した譜面を表示
・腕ガチ、指ガチ・微縦連、16分乱打、ディレイに分けて表示
・各フィルター結果からランダムコースを作成


必要なもの
----------
・Windows
・Python 3.11以上
・beatoraja

外部Pythonパッケージの追加インストールは不要です。


カスタムフォルダーを作るまで
----------------------------
1. ZIPを任意のフォルダーへ展開します。
2. start_oraja_constellator.bat を実行します。
3. 「設定・管理」タブで、beatoraja本体フォルダーと使用するプレイヤーを指定します。
4. ［読込・再読込］を押します。
5. 「カスタムフォルダー設定」タブで、使用する難易度表とフィルターを選びます。
6. 「設定・管理」タブで［差分を解析］を押します。
7. 解析終了後、［DBへ追記］を押します。
8. ［カスタムフォルダーへ反映］を押します。
9. beatorajaを再起動します。


普段の使い方
------------
一度差分解析を済ませた後は、難易度表やフィルターの設定を変更して
［カスタムフォルダーへ反映］を押すだけで更新できます。

楽曲や差分を追加した場合は、次の順番で更新してください。

1. beatorajaで楽曲更新を行う
2. このツールで［差分を解析］を行う
3. ［DBへ追記］を行う
4. ［カスタムフォルダーへ反映］を行う
5. beatorajaを再起動する

内容が変わっていない差分は、保存済みの解析結果を再利用します。


画面の使い方
------------
対象難易度表
  カスタムフォルダーへ使用する難易度表を選びます。
  項目を右クリックするとON/OFFを変更できます。
  見出しをクリックすると、使用状態・譜面数・難易度表名で並べ替えできます。

対象フィルターセット
  使用するフィルターのまとまりを選びます。
  項目を右クリックするとON/OFFを変更できます。
  ［↑］［↓］で並べ替えると、生成されるフォルダーの順番も変わります。

フィルター詳細設定
  各フィルターの表示／非表示や数値を変更します。
  数値を変更すると、画面上の名称と生成フォルダー名にも反映されます。

  例
  ・最終プレイから7日以上経過
  ・スコア率80%未満
  ・最小BP50以上


作成される主なフォルダー
------------------------
譜面傾向
  ・腕ガチ
  ・指ガチ・微縦連
  ・16分乱打
  ・ディレイ
  ・判定保留

平均密度
  ・下位10%
  ・下位25%
  ・中央50%
  ・上位25%
  ・上位10%

プレイ状況
  ・未プレイ
  ・最終プレイから7日以上経過
  ・最終プレイから15日以上経過
  ・最終プレイから30日以上経過

クリア状況
  ・FAILED
  ・ASSIST EASY
  ・HARD未達・EASY以上
  ・HARD
  ・EXH
  ・未FC
  ・最小BP30以上
  ・最小BP50以上
  ・最小BP100以上

スコア状況
  ・A未満
  ・AA未満
  ・AAA未満
  ・MAX-未満
  ・スコア率70%未満
  ・スコア率80%未満
  ・スコア率90%未満

譜面傾向の細分類は初期状態では非表示です。
必要なものだけ「フィルター詳細設定」からONにしてください。


ランダムコース
--------------
有効にした各フィルター結果から、初期設定では4曲のランダムコースを作成します。
通常のフォルダー一覧を圧迫しないよう、コースは「ランダムコース」フォルダー内へまとめます。


小型パネル
----------
「設定・管理」タブの［小型パネルの表示］から開きます。

プレイ中に変更しやすい次の条件だけを表示します。
・最終プレイからの経過日数 3件
・最小BP 3件
・スコア率 3件

数値を変更すると検索条件へ反映されます。
beatoraja側では、対象フォルダーを開き直してください。
フォルダー名の数値は、次回［カスタムフォルダーへ反映］を行ったときに更新されます。


詳しい設定と注意事項
--------------------
ここから下を読まなくても、上の手順で基本的な機能を利用できます。
必要に応じて確認してください。

解析対象
  差分解析の対象は、ONにした難易度表へ所属する差分です。
  差分数が多く時間がかかる場合は、対象難易度表を減らしてから解析してください。
  複数の難易度表に同じ差分がある場合は、重複を除いて解析します。

解析を途中で止める場合
  ［解析を中止］を押すと、安全な区切りで停止します。
  中止までに完了した結果は残るため、その後［DBへ追記］を押して利用できます。

4つの操作の違い
  ［差分を解析］
    BMS差分を読み取り、解析結果を一時保存します。

  ［解析を中止］
    完了済みの解析結果を残したまま、解析を停止します。

  ［DBへ追記］
    一時保存した解析結果を、ツールが普段使用するDBへ反映します。

  ［カスタムフォルダーへ反映］
    現在の難易度表・フィルター設定で、beatorajaのカスタムフォルダーを更新します。

解析中に［カスタムフォルダーへ反映］を押した場合は予約状態になります。
解析終了後に［DBへ追記］を押すと、続けてカスタムフォルダーへ反映します。

beatorajaの楽曲DBへの書き込み
  カスタムフォルダーを利用できるようにするため、songdata.dbへ
  bmscf_で始まる本ツール専用テーブルを追加・更新します。
  beatoraja標準の楽曲情報やプレイ記録には書き込みません。

  DB操作にはわずかな破損リスクがあるため、初回の書き込み前に
  songdata.dbを1度だけ自動バックアップします。

  バックアップは、ツール本体フォルダー内の
  data\backups\songdata
  に保存されます。
  .dbファイルがバックアップ本体で、同名の.jsonファイルには
  元のsongdata.dbの場所と作成日時が記録されます。

  問題が起きた場合はバックアップから戻すか、beatorajaで楽曲DBを再生成できます。

既存カスタムフォルダーの表示
  「設定・管理」タブの［カスタムフォルダー編集］から、
  既存カスタムフォルダーの表示・非表示を変更できます。
